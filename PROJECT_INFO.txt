WHAT THIS PROJECT IS
--------------------
A small TODO application that demonstrates the MERN stack. The Express
backend exposes a REST API for creating, listing, and deleting TODO items,
and stores them in MongoDB through Mongoose. The React frontend (built with
Vite) provides the user interface. In production the backend serves the
compiled React build as static files.

HOW IT WORKS
------------
1. The client sends HTTP requests to the Express API under /api.
2. routes/api.js validates and forwards requests to the Todo Mongoose model.
3. models/todo.js defines the stored document shape and talks to MongoDB.
4. index.js wires everything together and, after a client build, serves the
   React single-page app for all non-API routes.


HOW TO RUN
----------
1. Install dependencies:
     npm run setup
2. Start server and client together in development:
     npm run dev
   Or run them separately:
     npm run server   (nodemon index.js)
     npm run client   (Vite dev server in client/)
3. Production start:
     npm start        (node index.js, serving client/dist)

A MongoDB connection string must be provided via MONGO_DB_URI in .env
(see env-example for the expected format).
